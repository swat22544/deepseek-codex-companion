# DeepSeek + GLM 协作监看

本地只读工作面板。借鉴 awesome-design-md 中 Linear 参考的中性底色、细边框、分层和紧凑排版，保留项目已有的浅色/自动深色系统。模型使用 DeepSeek 蓝、GLM 青绿作有限区分，颜色同时配文字，不借用品牌标志。

## 信息顺序

顶部双模型身份与监看连接；两张模型卡展示最近100条记录内的活动/数量；左侧搜索、模型/状态筛选和任务列表；右侧详情、公开回复、活动、候选文件。卡片可筛选，不能启动模型。

“进行中”只表示监看记录；连接中断不代表模型失败。未知模型不能按预期配置伪装为已核验；历史缺backend按Harness兼容。候选始终标注待主代理复核。

## 交互和适配

复用原生按钮、select、tab键盘导航和可见焦点。频繁更新不加入装饰动画。hover限定精确指针；触摸目标至少44px，输入至少16px，保留浏览器缩放和安全区。宽面板左右分栏，窄面板上下分区；320px宽度也应能阅读与操作，长标题/哈希不能撑宽视口。

自动化验证涵盖双路筛选、组合搜索、空结果、连接状态、轮询/页面缓存和复制。浏览器窄视口结果不代表真机触摸或系统键盘验收。
