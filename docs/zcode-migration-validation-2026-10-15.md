# ZCode / GLM 接入与本地安装验收

验证日期：2026-10-15（Asia/Shanghai）。插件版本 **1.3.0**，Skill 修订 **2026-10-15-zcode-glm**。

当前支持两路：默认 Harness 的 DeepSeek-V41-Flash / Max，以及 ZCode 的 **Z.ai API / GLM-5.3-Flash / 最高（max）**。第二路使用标准 API `https://api.z.ai/api/paas/v4` 的 Chat Completions 服务；不替换为 Coding Plan 服务，也不移用 Harness 的能力评分。

## 实现与安装

- 使用已安装的 ZCode CLI **0.16.9**，通过后台 `app-server` 创建独立会话。版本变化时拒绝继续调用，等待重新核验协议。
- 运行时配置、工作目录和会话数据库隔离；禁用额外插件、Skill、Hook、记忆和再委派。根据模式只提供本次快照读取、搜索及候选写入工具。
- 在请求发出前验证标准端点、精确模型 ID、最高思考强度及完整工具集合，拒绝 HTTP 重定向和未经检查的传输。
- 只保存公开回复和白名单诊断。隐藏推理仅贡献活动长度；进程退出确认后删除本次临时原生会话存储。认证由 ZCode 已有配置提供，不复制到协作请求或公开材料。
- 安装器刷新自有插件、Skill 和市场副本中的文件，并保留组件根目录，避免 Windows 常驻服务占用工作目录时出现 `EBUSY`。全局 Hook 与其他插件不被覆盖。
- 源码、安装版 Skill/插件的 **63 个文件**完成逐项一致性检查；生成的 Node 路径及运行根配置单独核验。当前 **1.3.0 缓存的 26 个文件**与本地安装版一致。

这些约束属于应用层控制，不是操作系统沙箱。候选文件不会自动修改项目或运行命令。
