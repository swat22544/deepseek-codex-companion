# 1.0.3 自适应超时验证记录

2026-10-13 在 Windows、Node.js 24、DeepSeek Harness 0.2.0-rc.2 上验证。规则和迁移方式见[时间预算说明](../skills/deepseek-helper/references/timeouts.md)。这次验证针对时间控制、安装和监看集成，不重做既有能力评估。

## 自动化验证

仓库根目录运行 `node --test`：**70 项通过，0 项失败、0 项跳过**。

- 自动规模分类、UTF-8 字节边界、文件数量阈值、显式预算、旧 `timeoutMs` 和冲突输入校验。
- 注入单调时钟验证 30 分钟任务每 5 分钟产生进展、60 分钟任务每 10 分钟产生进展时，总预算仍按原截止时间到期。
- 无进展计时独立重置；空输出、重复、错误会话、旧尝试和监看心跳不用于续期；晚到事件不能恢复已过期任务。
- 本地模拟 Harness 启动真实 Node 子进程，确认总时限与无进展超时的分类、错误模型拒绝、Windows 进程树清理和大任务工具截止时间。模拟过程不访问模型服务。
- 独立审查发现并修复最终结算竞态：即使最终回复已在截止前收到，若进程在截止后、下一次定时检查前退出，也不能报告成功。总时限和无进展时限各有一项确定性回归用例。
- 监看数据白名单、两种超时说明、旧记录兼容、无效数值处理、监看记录中断提示、固定地址恢复及 HTTP 权限限制。

这些测试使用虚拟时间与缩短的真实子进程时限；**没有声称真实运行了 30 或 60 分钟模型任务**。

## 本地安装与实际调用

通过安装器先备份再更新 Skill 和插件，并使用 Codex 支持的插件安装命令加载 **1.0.3**。本机已有的固定端口服务配置和 watchdog 启动项保留。校验了 42 个源文件与安装副本一致；插件缓存中的对应文件也一致。MCP 启动、工具发现、只读调用及 UI 资源读取再次通过，HTTP 服务报告版本 1.0.3。

一次文件审查联调显式选择 `taskSize: "large"`，由安装后的 helper 发起，约 **7.9 秒**完成：

| 实际模型选择 | `deepseek-official / deepseek-flash / max`，核验通过 |
| 底层模型请求 / 受限工具调用 | 2 / 2 |
